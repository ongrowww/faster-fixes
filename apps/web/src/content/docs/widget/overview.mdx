---
title: Overview
description: Choose how to install the Faster Fixes widget on your site.
---

The widget is the feedback layer your Reviewers use on your site: they click an element, leave a comment, and the report reaches your Task board with a screenshot, the selector and a Diagnostic Trail. Every install path mounts the same widget, with the same options and the same behavior.
